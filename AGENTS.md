# Agent instructions

This repository is agent-portable. Read `PORTABLE_PROMPT.md` before using the radar. Codex users can use `SKILL.md`; Claude users can use `CLAUDE.md`; ChatGPT and other agents can upload or reference `PORTABLE_PROMPT.md` and run the same Python CLI. The scoring and report behavior lives in `scripts/radar_core.py` and must remain deterministic.
