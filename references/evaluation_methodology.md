# Evaluation methodology

The harness uses a small synthetic, labeled fixture only to verify mechanics; it is not a claim of forecasting accuracy. A future real evaluation must freeze an evidence cutoff, define emerging-skill outcomes before measurement, prevent future leakage, and report Precision@K, recall, false-positive rate, citation support, ranking stability, lead time, and confidence calibration only when labels are adequate.

Run the offline tests with `python -m unittest discover -s tests -v`. Expand the dataset with attributable historical records rather than inventing ground truth.
