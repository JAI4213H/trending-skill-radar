# Report format

Reports contain an executive summary, a capped top-5 comparison table by default, separate global-trend and personal-learning rankings, and a detailed report for every displayed candidate. Each detailed skill report includes rating, score breakdown, confidence, evidence coverage, maturity, historical comparison, supporting and contradictory evidence, current jobs, comparable-window growth where available, future potential, recommendation, and a practical next step. Expected growth is included only when a validated forecast record includes its horizon. Candidate names must be specific capabilities tied to a domain, tools, prerequisites, and a demonstrable outcome. Claims need an evidence ID and URL when available. Observations, interpretations, and forecasts are separate; unavailable values are shown as `Insufficient Evidence` or `Unavailable`.
