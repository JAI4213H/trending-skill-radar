# Report format

Reports contain an executive summary, a capped comparison table, separate global-trend and personal-learning rankings, methodology version, collection status, dimension scores, maturity, confidence, coverage, historical comparison, supporting and contradictory evidence, real-life adaptation guidance, learning order, monitor/skip decisions, and limitations. Claims need an evidence ID and URL when available. Observations, interpretations, and forecasts are separate; unavailable values are shown as `Insufficient Evidence`.
