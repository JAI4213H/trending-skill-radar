# Report format

Reports contain an executive summary, a capped top-10 comparison table, separate global-trend and personal-learning rankings, methodology version, collection status, dimension scores, maturity, confidence, coverage, historical comparison, supporting and contradictory evidence, current employment demand, comparable-window growth where available, and expected growth only when a validated forecast record includes its horizon. Candidate names must be specific capabilities tied to a domain, tools, prerequisites, and a demonstrable outcome. Claims need an evidence ID and URL when available. Observations, interpretations, and forecasts are separate; unavailable values are shown as `Insufficient Evidence` or `Unavailable`.
