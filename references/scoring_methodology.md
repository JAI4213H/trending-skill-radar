# Scoring methodology v2026.10

Each dimension is a 0–100 value supplied by evidence extraction or a validated user record. The default aggregate uses trend 30%, current practical/career value 25%, future potential 25%, and learning priority 20%, but only observed dimensions are included in the denominator. Coverage is the weight of observed dimensions; below 60% the result is `Insufficient Evidence`.

Confidence is independent: High requires at least three source types, 80% coverage, and no marked counterevidence; Medium requires at least two source types; Low is sparse or concentrated evidence. These labels are not calibrated probabilities. Historical growth requires two dated, comparable `activity` observations and returns unavailable for zero baselines.
